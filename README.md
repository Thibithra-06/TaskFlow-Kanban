# TaskFlow – Collaborative Sprint & Kanban Workspace

TaskFlow is a web-based Kanban task management workspace designed to organize tasks and track project progress through a simple three-column board.

## Features

- Clean and modern Kanban board layout.
- Three task management columns:
  - To Do
  - In Progress
  - Done
- Reusable task cards.
- High, Medium and Low priority labels.
- Task due date display.
- Add Task form interface.
- Responsive layout for different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation is required.
