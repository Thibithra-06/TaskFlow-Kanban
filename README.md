# TaskFlow – Collaborative Sprint & Kanban Workspace

TaskFlow is a web-based Kanban task management application designed to organize tasks, manage project activities, and track progress using a simple and interactive three-column board.

## Features

- Modern and responsive Kanban board interface.
- Three task management columns:
  - To Do
  - In Progress
  - Done
- Add, edit, move, and delete tasks.
- Drag-and-drop task management.
- High, Medium, and Low priority labels.
- Task due dates with formatted date display.
- Dashboard statistics and overall progress tracking.
- Search tasks by title.
- Filter tasks by priority and status.
- Save tasks automatically using LocalStorage.
- Restore saved tasks after refreshing the browser.
- Import five sample tasks from an external API.
- Loading message while importing tasks.
- Error handling for failed API requests.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- JSONPlaceholder REST API

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start managing your tasks.

No additional installation is required.

**Note:** Internet access is required to import sample tasks from the JSONPlaceholder API.
